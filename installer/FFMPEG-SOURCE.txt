StreamFirefly bundles a minimal FFmpeg 8.1.3 build for Windows x64 or ARM64,
licensed under the GNU Lesser General Public License version 2.1 or later
(FFMPEG-LICENSE.txt). It is configured without --enable-gpl or
--enable-nonfree, links no external libraries, and only remuxes media
(stream copy) and converts WebVTT subtitles. FFmpeg runs as a separate
executable invoked by StreamFirefly.

Corresponding source (same Release as these binaries):
https://github.com/rumoii/streamfirefly/releases/tag/v1.0.5
Download StreamFirefly-ffmpeg-source-1.0.5.tar. It contains the unmodified
upstream ffmpeg-8.1.3.tar.xz, the build recipe (recipe/build.sh with the
complete configure options, recipe/ffmpeg-lgpl.json with pinned source,
toolchain and binary SHA-256 values) and README.txt with rebuild steps.
Rebuilding from these inputs reproduces the bundled ffmpeg.exe byte for byte.

The same recipe is in the StreamFirefly repository under tools/ffmpeg/.
