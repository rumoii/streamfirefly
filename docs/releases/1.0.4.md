# StreamFirefly 1.0.4

版本：`1.0.4`。这一版修复 1.0.3 发布后用户反馈的两个问题。

## 修复

- 缓存捕捉的保存目录留空时，改为使用设置中的“默认保存目录”，不再固定写入 `%LOCALAPPDATA%\StreamFirefly\captures`（C 盘）。设置也为空时仍使用该目录；捕捉页的目录输入框会显示实际使用的路径。（[#2](https://github.com/rumoii/streamfirefly/issues/2)）
- 修复页面脚本变量被误识别为媒体地址：例如 B 站页面中的 `window.webAbTest` 会被截成 `window.webA`，生成一个无法下载的音频候选。媒体后缀之后现在不能再紧跟其他字符；同时修复内联 JSON 中转义斜杠（`https:\/\/…`）的地址被截断、解析到错误位置的问题。（[#1](https://github.com/rumoii/streamfirefly/issues/1)）

## 兼容与限制

- 两项修复都在扩展中；本地助手只更新了版本号，建议与扩展一起升级到 1.0.4。
- 已经保存在旧捕捉目录中的文件不会自动迁移，可以手动移动。
- 目前 B 站视频虽然不能直接下载（B 站的真实音视频流是 `.m4s` 分片），但可以使用资源列表中的“缓存捕捉”强行下载保存。
