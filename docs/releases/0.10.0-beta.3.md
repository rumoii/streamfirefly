# StreamFirefly 0.10.0 Beta 3 内测版

仅面向受邀测试人员，以 Pre-release 分发，不是稳定版、浏览器商店正式版或完整 1.0 验收。测试包标识为 `0.10.0-beta.3`，扩展与 Native Host 数字版本仍为 `0.10.0`。Beta 2 曾以 Actions 测试产物交付，本版不覆盖该产物或已有 Release。

## 相对 Beta 1 的更新

- 完善 iframe 深搜和 MSE 捕捉，以来源框架及文档身份隔离会话；支持来源切换、重复停止、导航后的部分结果保留和旧文档拒绝。
- 增加 Aria2 保存目录/文件名和 N_m3u8DL-RE 结构化参数配置、草稿检查；预览与实际工具交接复用参数生成。回执不代表外部下载完成，未知状态不自动重发。
- 增加识别规则逐条调试、独立 URL 提取及保存后的旧候选清理；提取结果不继承原请求敏感凭据、不自动发送外部工具，清理失败时明确显示部分完成。
- 设置页面统一分类导航，保留未保存草稿并修正切换时的留白与位置抖动。
- 高级深搜新增字符生成、数组拼接 HLS 清单发现，覆盖现有经典 Worker 与框架路径；有扫描预算及重入保护，不跨不相关调用猜测拼接。
- 新增浏览器候选到真实 Native/FFprobe 的下载验证；修复 MSE 测试片段寻址和追加失败漏报，避免把夹具失败误判为持久化失败。

## 发布门槛与证据

仅发布最终源码提交的干净 CI 构建。发布前必须通过类型/构建、单元与契约检查、三浏览器资源及发现测试、Native 集成、双架构包审计、x64 安装态捕捉、两小时捕捉和新增 HLS 下载闭环。任何失败都阻止 Release 发布，不改用旧包替代。


最终源码 SHA、CI 运行编号、两小时结果与附件 SHA-256 在 GitHub Release 正文中记录。分发仓库标签指向分发文档提交，不等同源码提交；包内 `PACKAGE-INFO.json` 记录实际源码来源。双架构构建不等于 ARM64 实机验证。

## 升级与回滚

从 Beta 1 或更早版本升级时同时更新扩展与 Host。升级前等待任务结束、关闭浏览器并退出助手，备份任务文件、检查点目录及已下载内容。软件界面仍显示 `0.10.0`，具体批次请核对包名、Release 和 `PACKAGE-INFO.json`。

本批不改变 Native 协议、任务存储或 MSE 数据格式，不自动迁移、清空未知或损坏数据。回滚时先保留升级后的数据副本，再成套恢复旧扩展/Host，必要时恢复升级前备份；不要在任务运行中升级或回滚。

## 尚未完成

- 动态 MPD 内容保留与 DASH 完整轨道选择、跨调用 HLS 拼接尚未实现。
- 捕捉仅保存开始后的 MSE 数据，不回溯历史缓存、不支持 DRM，也不新增 WebRTC 录制。
- 真实网站、真实外部下载工具、ARM64 实机及升级回滚仍待统一验收；Firefox XPI 是未签名临时测试包。
- 既有 Firefox lint 例外及开发依赖审计项未作为本版额外升级范围，实际发布检查以对应 CI 结果为准。

发布附件为 Windows x64、ARM64 内测 ZIP 和 `INTERNAL-SHA256SUMS.txt`。仅下载拥有版权或获授权的资源，请勿转发内测包、私有 Release 链接及测试数据。
