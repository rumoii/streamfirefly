# StreamFirefly 1.0.2

版本：`1.0.2`。

- 分为两个发行版，源码相同，由构建开关 `STREAMFIREFLY_EDITION` 区分：
  - **通用版**（`general`）：不限制网站。GitHub Release、Windows 完整包和签名 Firefox 扩展都使用此版本。
  - **Chrome 应用商店版**（`chrome-store`）：根据 Chrome 应用商店政策，不识别和下载 YouTube 内容；只通过 Chrome 应用商店分发。
- 一键安装本地助手：扩展检测到尚未安装本地助手时，显示“复制安装命令”。按 Win+R，粘贴并回车，即可下载、校验并安装与扩展同版本的助手；安装完成后扩展自动连接。首次安装扩展时会打开设置页说明此步骤。
- 新增 Release 附件 `StreamFirefly-install.ps1`，内含两个 Windows 完整包的 SHA-256，安装前校验。
- 扩展能区分“本地助手尚未安装”与“连接已断开”；助手版本不兼容时，提示一键更新。
- 设置页显示当前发行版和版本号。

通用版不限制网站，但能否识别和下载仍取决于网站本身；DRM、SAMPLE-AES、LL-HLS Part 不受支持。真实 ARM64 设备、真实网站覆盖及两小时持续捕捉需另行验证。
