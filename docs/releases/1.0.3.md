# StreamFirefly 1.0.3

版本：`1.0.3`。这一版重做了缓存捕捉，并改善新手上手体验，是第一个推荐所有用户使用的正式版。

## 缓存捕捉

- 新增“一键捕捉”：授权后自动刷新来源页，从播放器第一次加载数据开始录制，播完自动保存。修复了视频在开始前已缓冲完时录不到内容（0 字节），以及中途开始录制时缺少视频开头信息、无法生成文件的问题。
- 捕捉探针改为在页面加载开始时被动登记媒体源，先播放视频再打开流萤也能找到；Blob 地址被页面回收后仍能对应。找不到精确对应时，可以手动选择候选媒体源。
- 不刷新页面的普通捕捉会补入页面里已有的视频开头信息。
- 录制页改为分步引导，显示当前进度、加载等待提示和录制完成状态；技术选项收进“高级选项”；报错改为说明原因和下一步操作。
- 录制记录按时间倒序显示页面标题、时间和大小，可复制文件路径、删除单条记录或一键清理失败记录。本地助手同时修复了记录满 100 条后无法再录制的问题。
- 本地助手按格式校验初始化段，并以 FFmpeg 进度和输出容器轨道共同判定生成成功，能区分“没有新数据”“缺少开头信息”和“生成失败”。

## 资源列表

- 可直接下载的资源排在只能缓存捕捉的资源前面；同组内有封面的排在前面。
- 列表顶部提示“找不到能下载的视频？”，点击跳到可缓存捕捉的条目；悬停“缓存捕捉”会说明其用途。
- 打开面板后自动读取 HLS 清单，补全分辨率和时长，无需先播放预览。
- 资源详情会提示疑似分辨率更高或可直接下载的同一视频，并可一键跳转。
- 修复资源详情的预览区域在列表刷新时不停闪烁的问题。
- 页面内面板默认宽度从 420 调整到 480，避免大小、分辨率和时长被遮挡。

## 安装

- 一键安装命令和安装脚本会自动使用 Windows 系统代理（含 PAC 自动配置），curl 下载失败时改用 PowerShell 重试。
- 安装说明重写为面向新手的分步指南，并补充常见问题。

## 兼容与限制

- 扩展和本地助手需同时升级到 1.0.3。
- 缓存捕捉不处理 DRM；真实 ARM64 设备、所有网站覆盖和两小时持续捕捉需另行验证。
