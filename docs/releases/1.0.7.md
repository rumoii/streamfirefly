# StreamFirefly 1.0.7

这一版主要改进了下载功能：下载到本地的文件更好找出来，也一眼就能认出是哪个视频；同时新增了更新提醒，录制时视频暂停也会提示你。

## 新增：按网页标题命名

下载的文件默认用网页标题命名，不再是 `30080.mp4` 这样的乱码。服务器提供了文件名时，会拼在标题后面；同名文件自动加序号。想用原来的名字，在设置“常规 → 下载 → 文件命名”里选“资源原名”。

## 新增：按网站分文件夹

新下载的文件和录好的视频，会按网站放进保存目录下的子文件夹，比如 `bilibili.com`。以前下载的文件不会移动。不需要的话，在设置“常规 → 下载”里关掉“按来源网站分文件夹”。

## 新增：检查更新

每天第一次打开流萤时会检查一次新版本，有新版就在面板顶部提示；也可以在设置“常规 → 版本”里手动检查，或关掉自动检查。检查需要连接 GitHub，连不上时请开启浏览器或系统代理。Chrome 应用商店版由商店自动更新，没有这个提醒。

## 改进：下载页更好用

- 下载完成后，可以「打开文件夹」直接定位到文件，也可以「复制文件夹路径」。
- 下载页分成「下载」和「缓存捕捉」两栏，录制记录不用再去缓存捕捉页找；两栏都能只看当前页面、排序和搜索。
- 浏览器上的流萤图标会显示本页的下载进度，下完显示 ✓，出问题显示红色 ✕。
- 修复设置里“输出模板 → 文件主名称”不生效的问题。

## 改进：视频暂停时会提醒

录制时如果来源页的视频停了（比如一键捕捉刷新后没有自动播放），录制面板会提醒你点“去来源页播放”继续播放，不会再一直显示“正在录制”却录不到新内容。

## 升级

扩展和本地助手都有改动，请一起升级到 1.0.7，否则新的命名和分文件夹不会生效：按 [INSTALL.md](https://github.com/rumoii/streamfirefly/blob/main/INSTALL.md) 的「升级」一节，把新扩展覆盖到原来的文件夹并重新加载，再在流萤设置页复制安装命令运行一次。

**第一次安装？** 请按 [安装指南（INSTALL.md）](https://github.com/rumoii/streamfirefly/blob/main/INSTALL.md) 操作：先装浏览器扩展，再一键安装本地下载助手
