# StreamFirefly 1.0.0

版本：`1.0.0`。

本版本以浏览器扩展和 Windows 本地助手的完整 ZIP 包交付，提供 x64、ARM64、独立 Chromium 扩展及签名 Firefox 扩展。安装和回滚步骤见 [安装指南](../../INSTALL.md)。

- 保留网页媒体识别、HTTP 下载、HLS、实验性 DASH、任务恢复、悬浮工作区和缓存捕捉。
- 规则配置继续使用流萤自身的 JSON 格式，导入后可以编辑，保存前不会覆盖已有配置。
- 项目采用 MIT 许可证；第三方依赖和独立 FFmpeg 程序保留其许可。
- 发布包固定到同一源提交，记录构建工具和架构，并提供内外 SHA-256。

DRM、SAMPLE-AES、LL-HLS Part 不受支持。真实 ARM64 设备、真实网站覆盖及两小时持续捕捉需另行验证。
