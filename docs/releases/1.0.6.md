# StreamFirefly 1.0.6

版本：`1.0.6`。这一版主要改进缓存捕捉：录得更快，录好的视频更好找、更容易播放；同时放低了浏览器版本要求。

## 新增

- 缓存捕捉新增“录制速度”：可选 2、4、8、16 倍速，加速时静音播放，长视频不用等它实时播完。选择会被记住，录制中修改也立即生效；网站把速度改回去时会自动重设，改回次数太多就不再争抢并给出提示。停止或播完后，视频恢复原来的速度和声音。
- 缓存捕捉新增“优先录制兼容格式（H.264）”，默认开启：一键捕捉刷新来源页时，让网站改发 H.264，录好的视频用 Windows 自带播放器就能直接打开。开关下方会说明取舍：更看重画质就关掉，改用支持 AV1/HEVC 的播放器；只想下载下来就能播，保持开启。
- 录制记录新增“打开文件夹”：在资源管理器中打开并选中录好的视频。

## 改进

- 录制完成后，视频以网页标题命名，直接保存在保存目录里，不用再到 `capture-<id>` 子目录里找；原始轨道和记录仍留在子目录。重名时自动加序号，分段录制时加“片段N”。
- “复制路径”改为“复制文件夹路径”，复制视频所在的文件夹。
- 录制过程中一发现视频是 AV1 或 HEVC 就提示，并说明怎么播放；每条已保存的记录也都附有播放提示。
- 正在录制或正在生成文件的记录会有呼吸动效，长时间录制时能看出仍在进行。
- 一键捕捉过程中，步骤条不会再先跳回第一步，“我有权保存此视频”的勾选也不会被清掉。
- 扩展重新加载或升级后，未刷新的页面在深度搜索里显示“框架探针未运行，请刷新来源页面”，不再显示浏览器的英文报错。

## 兼容与限制

- 最低浏览器版本降到 Chrome/Edge 116、Firefox 140（安卓版 Firefox 142）。Chrome/Edge 141 以下没有关闭侧栏的接口，兜底侧栏打开后切回悬浮面板时，需要手动关闭侧栏。
- 扩展和本地助手都有改动，请一起升级到 1.0.6。本地助手新增 `capture-reveal-v1` 能力；助手还是旧版本时，“打开文件夹”会提示先更新，可以先用“复制文件夹路径”。
- 兼容格式只在一键捕捉刷新的那一次生效。部分网站的高清晰度只有 AV1/HEVC，开启后清晰度可能降低；网站不提供 H.264 时，仍会录到 AV1/HEVC，录制中会给出提示。
- 倍速太高时，网站可能自动降低清晰度，录制也可能分成几段，建议 2–4 倍。
