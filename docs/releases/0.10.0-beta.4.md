# StreamFirefly 0.10.0 Beta 4 内测版

仅面向受邀测试人员，以 Pre-release 分发，不是稳定版、浏览器商店正式版或完整 1.0 验收。测试包版本为 `0.10.0-beta.4`，扩展和 Native Host 数字版本仍为 `0.10.0`。Beta 2/3 的构建与失败记录保留，不覆盖已有产物或 Release。

## 相对已发布 Beta 1 的更新

- 实验性 DASH：保留完整动态 MPD，支持静态、单 Period、非加密清单，选择一条视频和一条音轨，或仅下载音频/视频；输出 MP4/MKV，无转码合并，不再直接下载完整 MPD。
- 深搜增加字符生成、数组拼接 HLS/MPD 发现，覆盖现有同源经典 Worker 与 iframe，有界扫描、不跨调用拼接。
- 资源优先布局：深搜点击打开详情，缓存捕捉打开独立控制页，外部工具归入资源行和批量操作；高级筛选折叠保留条件，减少主界面冗余。
- iframe 捕捉按框架与文档隔离，处理导航、重复停止、中断和部分结果；缓存只从开启后收集，不回溯旧数据。
- 工具结构化配置与草稿检查、规则调试、独立 URL 提取和保存后清理；提取候选不继承原请求敏感凭据，不自动启动外部程序，未知交接结果不自动重发。
- 设置页分类导航保留草稿，修正切换留白；内置任务继续复用统一队列、幂等提交与断连状态保留。
- 增加动态清单发现到真实 Native/FFprobe 下载闭环，修复多画质共享模板造成的 DASH 编号归一化干扰。
- 原 FFmpeg 上游构建已下架，固定依赖更新为 `autobuild-2026-09-08-23-15` 的 8.1.2 系列构建；x64/ARM64 分别校验 SHA-256，不使用浮动 latest 或跳过哈希检查。

## 更新与恢复

扩展与 Host 必须成套更新，通过新增 `dash-selection-v1` 能力识别 DASH 选轨；Native 协议主版本仍为 v3，任务存储版本不变。DASH 计划仅存于内存，同进程暂停或重试复用已完成分片；助手重启后保留历史，但必须重新解析创建任务，不自动续传。

升级前结束活动任务、关闭浏览器并退出助手，备份任务文件、检查点目录与已下载文件。界面版本仍为 `0.10.0`，批次以包名、Release 和 `PACKAGE-INFO.json` 为准。回退先保留新数据，再成套恢复旧扩展/Host 和必要的升级前备份；不要让旧 Host 自动执行新 DASH 未完成记录。

## 发布门槛

只发布最终源码 SHA 的干净 CI 构建。类型、构建、单元及契约、三浏览器资源与发现、HLS/DASH 下载闭环、真实 Native、双架构包审计、x64 安装态捕捉及两小时捕捉必须通过。先通过短链路，再对同一提交运行 7200 秒测试；任一失败均阻止 Release，不跳过采样或内存门槛，不替换成旧包。

Release 正文记录源码 SHA、成功 CI、两小时结果与附件 SHA-256；分发仓库标签指向分发文档提交，不等同源码提交。附件为 x64、ARM64 内测 ZIP 与 `INTERNAL-SHA256SUMS.txt`，以包内来源记录和哈希校验实际交付。

## 实验性与验收边界

- DASH 不支持动态直播、多 Period、SegmentBase/SIDX、时间轴间断、DRM、字幕选轨或重启续传；不静默回退到整份 MPD 执行。
- 不支持跨调用清单拼接、启动前缓存回溯或 WebRTC 录制。
- 真实网站、真实外部下载器、ARM64 实机和升级回退仍待统一验收。双架构构建与自动化压力测试不替代这些边界；Firefox XPI 是未签名临时测试包。
- 三份既有 ADR 格式问题及既有开发依赖审计项保留记录，不属于本版额外清理范围。
