# StreamFirefly 1.0.9

这一版可以直接在网页上点选想下载的视频；HLS 下载前能先播放所选范围确认；X 等网站下载下来没有声音的问题修好了，另外修复了直播停止保存、无后缀切片合并等几个下载问题。

## 新功能：在网页上点选视频

资源多的时候，很难认出哪一条是页面上的那个视频。现在资源列表的工具栏多了一个「拾取」按钮，用法和浏览器开发者工具的“元素检查”一样：点「拾取」，再在网页上点一下想要的视频、音频或图片，它和它的各个分辨率就会排到列表最前面，带“拾取”标签。拾取时鼠标指到的媒体会高亮并显示分辨率和时长，点网页不会暂停视频或跳转链接；按 Esc 或点「取消」退出。

- 播放器的控制层盖在视频上面也能选中；网页里嵌着的 iframe 也能拾取。
- 拾取到的图片会连同它的各个尺寸一起加入列表，即使没有开启“识别图片”。
- 正在播放的视频仍然会排在前面，位置在拾取结果之后。
- 资源较多时，列表上方会提示可以用「拾取」；关掉提示或用过一次后不再出现。

## 新功能：HLS 下载前先播放所选范围

在 HLS 解析页选好画质、音轨和时间范围后，可以先在页面里播放确认，再决定是否下载。播放内容和下载结果一致，支持暂停、拖动、重播和音量调节；加密视频也能播放。（[#14](https://github.com/rumoii/streamfirefly/issues/14)、[#16](https://github.com/rumoii/streamfirefly/pull/16)）

## 修复

- X 等网站的视频下载下来没有声音。这些网站把声音放在单独的音轨里，从某个分辨率下载时以前只拿到画面；现在会自动带上配套的音轨，从解析页打开也能选择音轨和字幕。
- 切片地址没有后缀的 HLS 视频，以前切片都下完了，最后却提示“FFmpeg 合并失败”。现在能正常合并；之前失败的任务重试即可。
- 直播录制中途需要重新登录或缺少密钥时，“停止并保存”会把已经下好的部分保存下来，不再卡在“正在停止”或合并失败。（[#13](https://github.com/rumoii/streamfirefly/pull/13)、[#15](https://github.com/rumoii/streamfirefly/pull/15)）
- 下载 HLS 时，网站的登录信息只发给视频原来的网站，不再带给其他网站的清单和切片。
- HLS 解析页换了画质后，不再因为新画质没有之前选的字幕而创建任务失败；只截取一部分时，生成的文件不再被本地助手拒绝；截取的起点超过视频结尾时，不再变成下载整段视频。（[#13](https://github.com/rumoii/streamfirefly/pull/13)）
- 没有标题的资源不再用 streamfirefly-download 之类的占位名，改用服务器给的文件名或网址里的文件名。（[#13](https://github.com/rumoii/streamfirefly/pull/13)）

感谢 @GmdsSeikai 提出并实现了 HLS 播放所选范围（#14、#16），还修好了直播停止保存的问题（#15）；感谢 @43aquarius 修复了停止合并、字幕选择、截取越界和占位文件名等一批问题（#13）。

## 升级

扩展和本地助手都有改动，请一起升级到 1.0.9：按 [INSTALL.md](https://github.com/rumoii/streamfirefly/blob/main/INSTALL.md) 的「升级」一节，把新扩展覆盖到原来的文件夹并重新加载，再在流萤设置页复制安装命令运行一次。

**第一次安装？** 请按 [安装指南（INSTALL.md）](https://github.com/rumoii/streamfirefly/blob/main/INSTALL.md) 操作：先装浏览器扩展，再一键安装本地下载助手
