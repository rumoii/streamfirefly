# StreamFirefly 0.10.0 Beta 1 内测版

本版本仅供受邀测试，标记为 Pre-release，不是稳定版或完整 1.0 验收。请勿转发安装包、Release 链接或测试数据。内测包版本为 `0.10.0-beta.1`，扩展与 Native Host 软件版本为 `0.10.0`。

## 本次更新

- 按职责拆分扩展后台、Native 任务执行和前端状态；规则与模板使用独立纯业务模块，增加模块依赖边界检查，移除被替代的共享作用域实现。
- 增加可配置资源规则，支持后缀、MIME、URL 正则、站点、大小与排除条件，以及排序、复制、导入导出和命中解释；规则求值有超时限制。
- 增加复制和文件名模板，支持声明式变量与字符串处理，不执行用户脚本。
- 增加 Aria2 RPC、HTTP、本地 EXE 参数调用和自定义协议交接；提供确认预览、敏感字段遮蔽、回执与去重，结果未知时不自动重试。
- 深度搜索按页面和框架管理状态，支持站点记忆、有界密钥候选及 HLS 密钥选择。
- 增加媒体缓存捕捉：来源选择、有界队列、认证回环 WebSocket、落盘确认和异常片段保留；跳转或编码变化分代保存，不跨时间线直接拼接。
- Chrome 增加 offscreen 权限，用于后台规则求值和捕捉传输。

## 升级与数据保护

必须同时更新扩展和 Native Host；新增 `integration-program-v1` 与 `capture-stream-v1` 能力握手，不支持新旧组件混用。升级前等待任务结束、关闭浏览器并确认助手退出，备份任务文件、检查点目录及已下载文件，再按包内 `README-INTERNAL.md` 安装。

回滚时成套恢复扩展与助手，保留新版本产生的数据副本，必要时使用升级前备份。不要用旧版直接覆盖新捕捉数据，也不要在任务运行期间升级。

## 验证与已知边界

- 本地功能验证通过类型检查、构建、37 项前端测试、38 项 Rust 测试、模块边界、扩展打包契约，以及 Native HTTP/HLS/队列和缓存捕捉集成测试。
- Chrome 捕捉测试覆盖真实 MediaSource 到扩展 WebSocket 传输，但接收端为测试替身；Native 捕捉落盘和 FFmpeg 合并单独验证。两者不等同于已安装扩展到已注册助手的完整链路验收。
- Edge 扩展和模拟 Native API 的界面交互测试通过。本地 Firefox 缺少二进制，仅完成构建、静态契约与 lint；CI 浏览器和包验收结果以对应运行记录为准。
- 真实 Aria2、N_m3u8DL-RE、自定义协议下载、已安装助手的浏览器捕捉全链路、长时压力、ARM64 实机和真实升级回滚仍待验收。
- 捕捉只保存开启后的媒体数据，不读取开启前缓存；缺少初始化段可能只能保留部分轨道，不支持 DRM。DASH 完整轨道选择不在本次范围内。
- 开发工具依赖链 `web-ext → addons-linter → image-size` 有 3 项既有高危审计告警；本版未强制升级或降级工具链。

## 产物与来源

提供 Windows x64、ARM64 内测 ZIP 和 `INTERNAL-SHA256SUMS.txt`。仅发布由指定源码提交干净构建、完成包审计的产物；源码 SHA、CI 运行编号及最终验证结果在 GitHub Release 中补充，包内 `PACKAGE-INFO.json` 提供来源与架构信息。

Firefox XPI 为未签名临时测试包，浏览器重启后需重新载入。ARM64 构建和静态包审计不代表 ARM64 设备运行验收。仅下载拥有版权或已获授权的资源，不绕过 DRM。
