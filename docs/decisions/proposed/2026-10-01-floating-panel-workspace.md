# Decision: 悬浮面板与工作区

Status: proposed

## Problem

原生侧栏缩小来源网页可用宽度，原工作区默认覆盖全视口并将资源卡片拉到全宽，快速查看会改变网页布局，复杂操作的空间也缺乏信息层次。

## Proposal

- 普通 HTTP(S) 页面由工具栏点击按需挂载一个 Shadow DOM 内 Vue 应用，初始为 420×640px 悬浮面板。展开为宽 1120px、视口高 80% 的工作区，最大化由用户主动选择；所有普通窗口保留网页边缘并可拖动、缩放。
- 窗口形态由前端维护，资源筛选由 background 按 `sourceContextId` 维护；同一个资源组件跨形态和功能页保留选择与滚动。收起停止预览，仍持有来源标签的嗅探连接；关闭按既有嗅探模式释放占用，下载任务独立运行。
- 面板与工作区共用“资源 / 下载 / 设置”导航，面板不再有底部按钮栏；标题栏按钮负责面板与工作区切换。面板内可查看资源详情和下载任务，不改变窗口形态；面板详情与工作区一样显示封面并可播放预览，没有封面时截取首帧回写为封面，列表行用已知封面作缩略图，不为列表批量加载媒体。侧栏没有来源标签页，无法附加预览请求头，详情只显示已知封面并保留“在工作区预览”。只有设置、HLS/DASH 解析和侧栏的“在工作区预览”会展开工作区。资源视图不再提供整表收起开关，`ResourceViewState` 删除 `collapsed` 字段，background 丢弃该补丁键。
- 下拉框、菜单和筛选弹层渲染在窗口内部并带 `data-sf-popover` 标记，不设 `aria-modal`。存在打开的弹层时，窗口壳和模态弹窗都不处理 Escape，由弹层先关闭并把焦点还给触发按钮；外部点击、滚动和窗口尺寸变化同样关闭弹层。
- 颜色、间距、圆角和字号只在 `extension-ui/src/theme/tokens.css` 定义，同一份令牌注入扩展页面和 Shadow DOM，按 `prefers-color-scheme` 切换浅色与深色。样式保持为 `?inline` 注入的全局 CSS 文件，不使用 SFC 样式块，因为 IIFE 构建不会把它们注入 Shadow DOM。
- 普通窗口不改变来源标题、宽度和滚动样式，宿主空白区域不接收鼠标事件。只有最大化保存并锁定底层滚动，还原与重复卸载恢复原样。响应式样式以窗口容器宽度为准。
- 每个窗口只拥有一个网页内界面；新来源就绪后才卸载旧来源。挂载按窗口串行处理，ready 必须匹配该来源、本次 attemptId 和顶层框架；超时或取消后的迟到消息不再发布界面所有权。
- `workspace.open` 的 `displayMode` 接受 `panel | workspace`，省略时进入工作区；工具栏显式请求 panel。ready 携带 attemptId；close 只卸载，不恢复侧栏。网页内调用使用发送者来源，不使用后来激活的标签。
- 本地布局使用 `floatingUiLayout` version 1，保存独立的 panel/workspace 矩形及小入口贴边位置；不存资源、地址、自动打开或默认最大化状态。坏值恢复默认，尺寸按当前可见区域约束，存储失败不阻断操作。
- Chrome/Edge 禁用工具栏自动侧栏行为，Firefox 同样默认进入网页面板；受限页或注入失败使用原生侧栏恢复入口。Firefox 侧栏 open/close 只能在原始用户操作中调用，普通网页消息不具备该权限，恢复侧栏内展开仍保留原浏览器限制。
- UI 参考 rumo-ui 的信息密度和组件分类，保留流萤品牌绿，以流萤 Vue 3 组件实现，不依赖参考库的 Vue 2 运行时；图标使用 Tabler Icons（MIT）的描边路径。

本方案部分取代 [原生侧栏与网页内工作区](2026-09-05-native-sidebar-and-page-workspace.md) 的入口、全屏、滚动和关闭规则；资源上下文、Native Host、可信配置和预览授权边界不变。

## Alternatives considered

- 继续原生侧栏并减少间距：能收紧 UI，但无法避免浏览器挤压网页，也不能自由定位。
- 独立应用标签页：改变浏览路径并增加来源会话管理，本次仍不采用。
- 默认全屏工作区：空间足够，但快速操作遮挡网页且单行内容过长，改为主动最大化。

## Risks

悬浮窗口会遮挡局部网页，通过移动、缩放和收起处理。注入仍受站点及浏览器权限限制。不同窗口共享最近一次布局偏好，各自运行状态及来源独立。完整扩展构建原子更新，不支持新旧脚本混装。

## Verification

新增几何、形态、滚动恢复、页面 Escape、脏设置、弹窗阻断、来源所有权、挂载失败、迟到就绪和超时测试，以及弹层优先处理 Escape、下拉框键盘选择、面板内详情不切换形态和 background 丢弃 `collapsed` 的测试。现有资源、任务、捕捉及下载单元测试继续执行。

构建后 UI 夹具验证拖动、缩放、选择与滚动保留、详情布局、尺寸记忆及多个视口；夹具使用模拟扩展与 Native API。Chrome、Edge、Firefox 的独立配置验证真实扩展资源发现、按需注入、共享筛选、滚动和导航清理。安装包发布、站点鉴权媒体与人工浏览器工具栏验收另行记录；本记录尚不标记为已发布实现。

本地验证通过 `npm run typecheck`、`npm run validate:extension`、`npm run test:unit`（121 项 UI 单元测试、47 项捕捉运行时测试及扩展脚本回归）、`npm run test:ui:browser` 和 `npm run test:browsers`。UI 夹具覆盖 1366×768、1920×1080、2560×1440、430×640 视口，并验证面板内详情与下载、筛选弹层的 Escape 顺序和深色配色；真实扩展测试调用生产工具栏处理函数，验证按需面板与收起后继续嗅探，不代替人工点击工具栏验收。

## Rollback

恢复上一版完整扩展构建并重新加载。旧版忽略新增布局键，无需迁移任务或 Native Host 数据。仍遵守既有扩展与助手版本配套要求。
