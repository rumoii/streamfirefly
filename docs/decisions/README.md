# Engineering decisions

Material decisions that affect StreamFirefly interfaces, lifecycle, security, packaging, or compatibility live in this directory.

- `proposed/` contains choices that are under review or not yet fully shipped and verified.
- `implemented/` contains shipped decisions with source, artifact, and applicable browser or field evidence.
- `rejected/` contains declined choices only when retaining the rationale prevents a likely future mistake.

Each decision keeps the same file name when its lifecycle changes. Do not retain copies in more than one lifecycle directory.
